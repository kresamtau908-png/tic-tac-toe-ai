# 接待〇✕ゲーム

AI と対戦できる〇✕ゲームです。HTML / CSS / JavaScript（ライブラリなし）で作りました。

## 遊び方

- あなたは〇（先攻）です。マスをクリックすると〇を置き、すぐに AI が✕を置きます。
- 決着がついた後にマスをクリックすると、もう一度遊べます。
- 画面下のラジオボタンでモードを切り替えられます。
  - **激ムズモード**：AI が最善手を打ちます。絶対に負けません。
  - **接待モード**：AI がわざと一番悪い手を選び、勝たせてくれます。

## 工夫したところ

- AI の思考に **ミニマックス法** を使っています（`ai.js`）。
  - 打てる手をすべて試し、相手も最善を尽くすと仮定して、最終的な勝敗の評価値が一番良い手を選びます。
  - 接待モードでは評価の向きを逆にして、一番悪い手を選ぶようにしています。
- 盤面は 3×3 の二次元配列で管理し、〇=1・✕=-1・空=0 として、各ラインの合計が ±3 になるかで勝敗を判定しています。
- モードに合わせて背景色が変わります。スマートフォンでも遊べるよう、マスの大きさを画面幅に合わせています。

## 使用技術
